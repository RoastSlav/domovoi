# Domovoi web UI

React + TypeScript + Vite. Built into `web/dist` and embedded in the hub binary with the `embed-ui` feature (ADR 0006).

## Develop

```sh
npm ci
npm run dev          # http://localhost:5173, proxies /api and /hooks to a hub on 127.0.0.1:7420
```

Point the proxy at another hub with `DOMOVOI_HUB_URL=http://host:7420 npm run dev`.

## Check

```sh
npm run lint
npm run typecheck
npm test
npm run build
```

## API types

`src/api/openapi.json` is generated by the hub (`cargo xtask openapi`) and `src/api/schema.d.ts` by `npm run gen:api`. Never edit either by hand; CI fails if they are stale.

Only files in `src/api/` may talk to the network. Features use the typed hooks exported from there.
