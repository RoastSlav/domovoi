# FAQ

## Is Domovoi ready to run on my servers?

No. The project is pre-alpha: the runtime libraries and UI are under active development, but
the `domovoi` binary does not yet expose production hub or agent commands. There are no
supported releases, images or upgrade path.

## What can I run today?

The [quick start](quick-start.md) runs a local development hub with fake hosts, a seeded
incident and a temporary database so you can explore the web UI. It is not a monitoring
deployment.

## Why do the guides describe features I cannot install yet?

They document the accepted product design and the runtime components being implemented. Each
installation and operational guide calls out whether it is available in the current preview.
