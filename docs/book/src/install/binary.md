# Binary and systemd

There is no supported binary installation yet. No release archives or installer are
published, and the current `domovoi` binary does not start a production hub or agent. Do not
install a source build as a service on a machine you depend on.

The first release is planned to provide verified archives, a one-line installer, hardened
systemd units and first-run configuration. For now, use the [development quick
start](../quick-start.md) to preview the UI with fake hosts and incidents.
