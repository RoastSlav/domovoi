# Container-mode agent

Container-mode agents are not available as a supported deployment yet. There is no agent CLI
or published image, so this is not ready for Unraid, TrueNAS SCALE or Synology.

The first release is planned to document host mounts, a Docker socket proxy and the trade-offs
for SMART access. For the currently runnable development preview, see [Quick
start](../quick-start.md).
